# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-09-27

### Added

- Initial public release of Diapo Core.
- Slide management and navigation engine.
- List and fullscreen presentation modes.
- Keyboard, mouse, and touch navigation.
- Incremental content support (`.next`).
- URL-based routing and deep linking.
- Progress bar integration.
- Automatic slide timers.
- Accessibility support.
- Presentation tracking events.
- Automatic initialization from HTML data attributes.

### Notes

Diapo Core provides the presentation engine only.

For the official presentation theme, see Nimbus.
